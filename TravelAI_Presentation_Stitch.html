01 · Problem Statement

What's missing in
Tamil Nadu tourism?

Existing platforms solve logistics — booking, routing, pricing. None deliver cultural intelligence or make heritage relationships queryable.

🏛️
No heritage depth
Visitors book hotels near Brihadeeswarar but cannot learn who built it, which dynasty, or how it connects to 40 other Chola temples across the Kaveri delta.
🕸️
Unmodelled relationships
300+ heritage sites connected by dynasty, architecture, and tradition — never structured or made queryable. The network is invisible to travellers.
🗣️
No Tamil language access
80M+ Tamil speakers globally. Zero tourism platforms deliver heritage content natively in Tamil with audio guides, transliteration, and Tamil script names.
🤖
Generic AI responses
General LLMs give surface travel tips. No platform uses specialised prompting for dynastically accurate, architecturally rigorous heritage intelligence.

04 · Platform Features

Tech Stack & Key Features

v5.0 is purely additive — zero removals, zero breaking changes.

🗺️
Dual Map System
Ola Maps primary (India-optimised). Leaflet + OpenStreetMap free fallback. Connected Heritage Map shows SNA-derived site networks.
🔊
Sarvam AI Audio Guide
Tamil TTS via Bulbul v1 (Meera voice). Every place gets a Tamil audio guide. Tamil script + Roman transliteration under all place names.
🤖
Chennai AI Agent
Autonomous agent running 6 parallel AI sub-queries per site — architecture, dynasty, arts, visitor intel, neighbourhood, street food.
📸
Rich Media Layer
Multi-image galleries + fullscreen lightbox. YouTube documentary strip with in-app modal player. 360° virtual tour links.
🏛️
Knowledge Panels
Expandable cards: dynasty badge, architectural style, ASI/UNESCO status, significance, epigraphic records, best photo time.
⏳
Historical Timeline
AI-generated visual timeline of Chennai's 2,000-year history. Dynasty-coloured nodes, horizontally scrollable, expandable events.
🍜
Street Food Map
Interactive Leaflet map — 8 iconic Chennai food spots at verified coordinates. Emoji markers, dish info, timing, price.
🎭
Events Calendar
AI-generated Chennai 2026 events — Margazhi Season, Book Fair, Arubathumoovar. Filterable by type.
⚡
Performance
24hr localStorage cache. Dynamic Leaflet import. Unsplash CDN. Framer Motion. Three.js 3D landing. Vercel CDN deployment.
